## 4. PC仿真必测清单

TB需要有限运行时间、失败非零退出和明确断言；只“波形看起来正常”不是自动回归通过。
协议golden model修正后，至少一组期望报文来自独立资料/实机，不由相同组包函数生成后再自证。

| 模块 | 关键场景 | 断言/判据 |
|---|---|---|
| UART TX | 连续字节、长64B帧、背压、复位在帧中 | 位长/LSB/停止位；停止位结束才允许释放 |
| UART RX | 中心采样、短毛刺、相位偏移、停止位错、break | 非法输入不生成valid反馈；错误可恢复 |
| SCS组包 | PING/READ/WRITE/SYNC_WRITE、非对称16位值 | 字节序、LEN、checksum逐字节与独立锚点一致 |
| SCS解析 | 前导垃圾、半帧、错ID、坏CS、超长、粘包、迟到响应 | 无合法完整包不更新；不会死锁/越界；正确重同步 |
| AXI | AW先/W先/同拍、B/R背压、WSTRB、只读/无效地址写 | 每合法事务恰一个响应；背压稳定、错误无挂起 |
| 参数提交 | 8路跨时隙更新、重复CMD/seq、非法ID/角度/速度 | 旧active完整保留；拒绝非法配置、不截位运动 |
| 快照 | 状态更新与PS读取交叠、时间高低字、seq回绕 | 一份快照内部一致；PS可发现未完成/新快照 |
| 调度 | 最长合法回包、无首字节、半包、错误后下一ID、优先卸力 | 时隙有界，轮询公平；错误不扩散到下一路 |
| 接触 | 单通道先hit、方向负载、噪声、门限连续样本 | 不持续给已接触通道加目标；不把方向位当负载 |
| 到位 | 任一必需通道无效/过期/掉线、全部缺失、空mask | 不能到位/抓稳；配置空mask被拒绝 |
| 超时 | 预张/闭合/释放超时 | 明确timeout/fault，不误报grasped |
| 保护 | 在每个FSM状态注入急停、过温、过载、掉线、heartbeat停止 | 故障优先，普通CMD不能绕过锁存，保护不依赖PS线程 |
| 恢复/复位 | 按键抖动、故障未解除clear、复位在TX/RX/握持中 | 不自动运动；清故障条件严格；记录舵机可能保留旧目标 |
| 集成 | PS提交与总线回包、反馈过期、故障同周期IRQ清除 | 端到端序号一致、新保护事件不丢失 |

不把当前VirtualServoBus零传输延时模型用于证明线速预算；从机TB必须建请求/响应字节时间、返回延时和故障时序。

## 6. 真实抓取签收口径

硬要求：真实灵巧手动作由PL总线控制；首版必须有受控预张、闭合、保持、释放和保护证据。
建议的首版测试规模：队长确认1个安全对象、1套有效计划，连续完成10次抓取-保持5秒-释放；每次保存结果，不删失败试次。
**10次/5秒是建议验收值，尚未由用户或队长冻结**；不可据此声称满足完整项目15类×20次指标。

每次判定应同时满足：

1. 真实对象被手稳定抓住，保持期间未继续危险加力、未明显滑落；队长现场观察并签收。
2. 输入来自已标定GraspPlan，日志/ACK/FSM/反馈序号与视频能对应。
3. 有效反馈、接触/到位条件符合冻结策略；空载到位或timeout不算成功抓取。
4. 释放完成有新鲜到位/现场观察；保护测试无绕过，故障解除后需显式重新使能。

若10次中出现失败，记录成功数、全部试次和原因，修复后另开新实验批次；不能把多次重试后的成功写成100%。
整手未在手、转换器未验证或只有serial后端成功时，结论为“尚未满足第一版PL真实抓取验收”，不是默认降级通过。

## 7. 性能对比方法与统计口径

### 7.1 先使对比公平

现有backend_serial与sim/候选RTL帧序列、超时和FSM不相同；这些差异会混入所谓“FPGA抖动收益”。
比较前统一同一手、对象、标定、计划、速度、总线1Mbps、帧序列、回读数/顺序、回复级别、故障策略和周期。
使用同一Z19，软件后端保留其真实Linux调度和USB传输开销，明确这属于整个实现路径的比较。
报告另区分PL内部时隙确定性与真实线上动作时序，不能把FPGA计数器和软件墙钟的不同单位直接画一起。
只有无法统一的因素需单独列出，不能先保证性能优越再选择数据。

### 7.2 原始采样与时间基准

定义周期起点 `t_k`，周期 `delta_k=t_k-t_(k-1)`，周期偏差 `e_k=delta_k-T_nominal`。
P99抖动采用 `quantile(abs(e_k),0.99)`，同时给signed偏差、min/max、均值、标准差、样本数和丢样数。
每个条件建议至少100000个完整周期；500Hz约200秒。空闲和PS高负载分别采样，warmup、采样区间、负载命令与时钟单位须记录。
建议目标：正常条件overrun=0、在冻结时钟基准上周期P99绝对偏差≤1µs；这是设计目标，未测量，外部频率误差另报告。

不能靠PS低速poll TIMESTAMP/CYCLE_INTERVAL寄存器重建所有周期的P99：它可能只看到部分周期并发生采样偏差。
后续需选择事件时间戳FIFO/环形缓冲批量导出（记录seq与drop），或具有合适存储/导出能力的仪器采集周期标记。
若使用记录缓冲，深度/映射/读出与丢样计数需在接口冻结前补充；现有v0.3草案只给诊断寄存器，**尚未实现连续记录流**。
ILA短窗口用于具体事件时序，不凭短波形宣称已覆盖100000周期；若采用storage qualification，也记录能力与覆盖范围。
32位1µs时间戳约71.6分钟回绕，差值按无符号模2^32计算；跨多个回绕/长时日志使用64位或扩展序号。
总线电气/实际串行边沿由示波器独立核对，避免自家计数器既生成节拍又单独证明节拍精度。

### 7.3 除抖动之外必须报告的指标

| 指标 | 定义/单位 | 证据与注意点 |
|---|---|---|
| 下发频率 | 实际SYNC_WRITE周期，Hz | 与反馈/执行器内部频率区分 |
| 反馈年龄 | 每路last_good至当前最大年龄，µs | 500Hz/2路名义全扫8ms，实际含故障与时隙相位 |
| 逻辑保护延迟 | 输入/有效异常反馈→保护锁存，µs | ILA，用采样时钟换算 |
| 安全帧延迟 | 保护锁存→首/末安全包字节，µs | ILA+示波器；含当前帧残余与恢复等待 |
| 执行器/机械停止 | 包尾→执行器停止或卸力 | 实机测；没有运动测量能力就标未测，不冒充逻辑延迟 |
| 通信健康 | timeout/CRC错误/overrun/掉线计数 | 线束/电源与测试时长同时记录 |
| 抓取成功率 | 成功/总试次，按对象/计划分组 | 不删除失败，样本少不泛化 |
| FPGA资源 | LUT/FF/BRAM/DSP、频率 | 工具版/bit版/ILA开关一致 |

没有独立机械运动测量条件时，可先交逻辑与总线保护测量，机械延迟明确未量化；是否满足实物安全签收仍由现场试验和队长确认。
不要将P99周期抖动、反馈轮询年龄与保护机械停止时间混成一个指标。
