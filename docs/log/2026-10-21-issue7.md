## 实现

- FakeRobot 完整七阶段 DRY_RUN；物理 XYZ 和关节角保持 None。明确 begin_run 唯一会话、连续序号、重复/过期/未确认/未标定拒绝；独立取消事件可中断延迟，STOP 后必须显式建立新会话；故障/超时锁定须重建对象。
- RoArmSerialRobot 默认断开，SDK 只在 explicit real + port + 当前现场确认 + connect 后构造。进程内端口独占、有限写超时、完整写计数、单次请求，失败不重发。QUERY 字段/范围校验、radians→degrees，并使用 SDK 已恢复的夹爪方向。
- 单独记录 SENT 和至少两条到位反馈后的 FEEDBACK_CONFIRMED。运动返回 bytes 不能作为完成；缺失、非法或不达目标反馈会失败/超时并锁定。
- 默认探针为 Mock 七阶段，输出放本工作树 `output/pc/issue7/`。真实 CLI 仅查询，须额外确认，不开放运动入口。
