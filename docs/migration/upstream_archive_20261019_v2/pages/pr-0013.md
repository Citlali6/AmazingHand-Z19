## 实现与部署

- 保留原 standalone/LPD 配置，新增 `linux-sd`：128-bit M_AXI_HPM0_FPD → SmartConnect → 原 HIL 核心，4KiB@0xA1000000，时基200703980Hz；沿用 amazinghand-hil/1，无软件PL回退。
- `build.tcl` 生成独立工程/bit/XSA，按板端实测周期重新检查时序。PS IP 名义时钟177.776MHz与当前FSBL配置不同，禁止把此XSA的psu_init/FSBL用于运行中的Linux；本流程是PL热加载包，不是新SD启动镜像。
- `package_linux.py` 核对BD、bit/XSA一致性和时序/DRC，调用Bootgen2020.1生成bin，打包manifest及板端文件。
- `linux_hil.py` / `hil-service.sh` 提供preflight/load/start/stop/status/restore-camera；核对内核、时钟、HPM位宽、驱动占用、地址和哈希。所有新增文件/日志/PID位于 `/run` tmpfs，临时固件搜索路径加载后恢复。
- 继承此前选择性RTL修复与XSim证据；本轮不重写核心、不重复跑XSim。未改相机工程/bit/XSA、SD启动文件、Linux安装目录，不接物理舵机，不执行PS初始化、拨码或重启。
