### FMC-HPC 转接板是什么？

Z19 的 FPGA 引脚全部收在一个叫 **FMC** 的高密度连接器里（行业标准，类似显卡的
PCIe 插槽，约 400 触点，杜邦线插不进、手焊不现实）。转接板一头插 FMC1 插座，
另一头变出 2.54mm 排针（STM32 板上那种针），纯粹"换接头形状"，无任何芯片：

```
Z19 FPGA 引脚(L17) → FMC1 插座 → [FMC 转接板] → 2.54 排针
    → 杜邦线 → TXS0108E 电平转换 → 舵机 DATA
```

购买确认两点：① **HPC 型**（Z19 FMC1 是高密度 HPC，不是 LPC）；② 引出 **VADJ 与 GND**。

### 为什么要 TXS0108E 电平转换？（依据：Z19 手册 39/31 页）

- FPGA 的 IO 分组叫 **bank**，每组共用一根供电（VCCO），组内引脚的电平上限由它决定。
  Z19 手册 39 页原文：FMC 信号"电平标准为 1.8V 或者 1.2V（跳帽 J5 来选择）"——
  即这些引脚的 bank 上限 1.8V。
- **过压即损坏**：5V 舵机信号进 1.8V 引脚 → 芯片内部 ESD 二极管强制导通 → 烧 bank。
- 反向也不通：1.8V 输出驱动不动 5V 舵机（其输入阈值 ~2V）。
- **旁证**：手册 31 页，ALINX 自己在 SD 卡上（1.8V bank ↔ 3.3V SD）就是加
  TXS02612 电平转换芯片——同一块板、同一个问题的同款解法。

## 接线铁律（两阶段通用）

1. 舵机 5V **永远**来自独立电源，严禁从 STM32 / Z19 / USB 口取电
2. 舵机电源负极必须与控制器 GND **共地**
3. Z19 阶段：FMC1 跳帽 J5 置 1.8V 档后才插 TXS0108E（docs/refer/Z19_key_specs.md）
4. 上电顺序：先开舵机 5V，再给控制器上电；断电反序
