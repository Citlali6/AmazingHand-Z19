# 硬件采购清单（ AmazingHand-based-on-FPGA ）

> 更新：2026-10-06 · 按"先宿舍测试台、后 FPGA 整机"分两批。
> 预算合计：约 150~330 元（不含已有 ST-Link / 杜邦线）。

## 两阶段硬件需求对照（先看这个）

| 硬件措施 | STM32 测试台（现在） | FPGA Z19（之后） | 原因 |
|---|---|---|---|
| 舵机独立 5V 电源 | 需要（单舵机可用充电头凑合） | **必须且要求更高** | 舵机自己的要求：8 只整机峰值 ~10A，USB/开发板供电必崩 |
| 电源与板共地 | 必须 | 必须 | 信号参考电平 |
| 电平转换（1.8V↔5V） | **不需要** | **必须** | STM32 PA9 是 5V 容忍脚；Z19 FMC 是 1.8V HP bank，直连烧板 |
| FMC 转接板 | 不需要 | 必须 | Z19 的 IO 都在 FMC 连接器上 |
| STM32F103 透传板 | 主力 | 退役（留作对比基准） | PL 侧 RTL 将接管它的角色 |
| USB 相机 / 麦克风 | 可选（PC 开发用） | 必须（板端 USB3.0） | 视觉与语音输入 |

## 已持有（无需购买）

- STM32F103C8T6 最小系统板 + ST-Link V2（宿舍测试台透传，之后退役备用）

- PC（Win11）

## 接线铁律（两阶段通用）

1. 舵机 5V **永远**来自独立电源，严禁从 STM32 / Z19 / USB 口取电
2. 舵机电源负极必须与控制器 GND **共地**
3. Z19 阶段：FMC1 跳帽 J5 置 1.8V 档后才能插 TXS0108E（docs/refer/Z19_key_specs.md）
4. 上电顺序：先开舵机 5V，再给控制器上电；断电反序
