# 项目框架（现行）——RoArm-M2-S × Z19 视觉抓取与 FPGA 控制

> **2026-10-20 正式替代原可穿戴 AmazingHand 八舵机工作目标。** 原文记录了早期真实的研究思路、预期指标与分工，但现已过期；历史全文仍保存在本文件的 Git 提交历史中，请勿使用旧日期/旧分工安排现在的 Codex 任务。

本文件为团队方向摘要；更详细的事实与验收要求以 [十天方案总入口](relaunch_20261020/README.md)、[架构](relaunch_20261020/SYSTEM_ARCHITECTURE.md)、[执行日程](relaunch_20261020/TEN_DAY_EXECUTION.md)、[规范](relaunch_20261020/DOC_STATUS_AND_RULES.md) 为准。

## 1. 科研/工程问题

如何把成熟成品机械臂的真实执行能力与 Zynq UltraScale+ 的 PS 感知/规划、PL 确定性动作监督相结合，在非常短的开发周期内交付**可重复、可测量、有安全边界的实体视觉抓取系统**？

本期系统应用定位：固定桌面轻量物体分拣、课程与嵌入式 FPGA 参赛原型；**不承诺医疗/残障辅助的安全适用资格**。原可穿戴设想是历史项目方向，不作为本次验收对象。

## 2. 演示场景（必须真机）

固定俯视实验室 USB 摄像头、稳定桌面和轻质方块。用户在界面选择目标并确认，摄像头真实帧中检测物体位置，经标定映射到机械臂基座坐标，Z19 PS 规划受限抓取阶段。每个阶段的实际机械臂指令在发出前经过 PL 状态机授权/超时/STOP 检查，PS 再通过 USB 串口控制微雪 RoArm-M2-S 原厂 ESP32；反馈回到 Z19 并形成可审计记录。要求变动目标位置重新测量后抓放，不能预录动画。

## 3. 实施边界

| 角色 | 当前职责 | 不做的事 |
|---|---|---|
| Z19 PS Cortex-A53 Linux | 视频源读取/外部 PC 视频接收、目标定位/标定、任务规划、串口桥、反馈、界面 | 无证据时不称 YOLO 多类别或全板端实时完成 |
| Z19 PL FPGA | 动作阶段、原子授权、会话/序号/过期/超时验证、STOP锁存，能验证拒绝新动作 | 不宣称自己通过 FMC 直接驱动 RoArm 舵机，也不冒充电流/力矩伺服 |
| RoArm-M2-S ESP32 | 原厂逆运动学和舵机/夹爪执行 | 未验收前不宣称已完成真实抓取 |
| USB UVC 相机 | 固定平面目标定位 | 不从一帧 RGB 直接承诺任意3D物体可抓 |
| 人机入口 | 手动确认必备；语音是 #12 P1 选项 | 语音不能绕过主控与 STOP |

## 4. 功能和验收

- P0：Z19 正确识别 USB 串口和真实 RoArm 反馈，低速真实受控动作。
- P0：固定摄像头提供真实新鲜画面，通过标定桌面坐标在三个位置触发不同抓取目标。
- P0：PL 在每个阶段真实参与授权，非法/过时/乱序请求被拒绝、STOP 与断链可观测，保存真实 bit/bin SHA 和实验记录。
- P0：机械臂真实抓取、搬运、放置轻质物体，人工物理断能可用，包含失败日志。
- P0：可从最新 main 与经过明确许可的现有硬件复现。
- P1：Vosk 中文语音、多类别 NCNN、ROS2/MoveIt/额外仿真，主链验收前不得占用关键资源。

**当前状态（2026-10-20）：上述新系统尚未完成联调和验收。** 原 IMX214 相机-only、MJC1 R2/AHIL HIL-only 的历史真实成果可继承，但旧 camera+HIL 组合 bit 仍不可部署；旧八执行器 MuJoCo 不是 RoArm 模型。
