# Amazing Hand 智能辅助手 — 我们要做什么

> 赛道：全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道 · 3.3 自主选题
> 板卡：ALINX Z19（XCZU19EG）· 决赛：2026 年 11 月
> 设计哲学：**模糊性交给 AI（PS/DPU），确定性交给 RTL（PL）**

---

## 1. 一句话

做一个**人机协作智能辅助手**：人说一句话 → 系统在桌面上认出目标物体并算出尺寸 → 告诉人手该往哪儿移 → 人手带着 AmazingHand 就位后，系统自动完成抓取，抓多紧由 FPGA 实时力控决定，全程跑在一块 Z19 上，不依赖云端和外部电脑。

## 2. 演示场景（评委看到的流程）

1. 桌面摆放物品集（15 类规则小物体），俯视相机对着桌面，AmazingHand 由人手持；
2. 对麦克风说：**"抓起香蕉"**；
3. 屏幕显示：YOLO 检测框 + 类别 + 估计尺寸 + 抓取模式（如"包握、张角 40°、力矩上限 70%"）；
4. 人手持手靠近，屏幕/语音实时引导："左移 2cm → 旋转 15° → 就位"（基于手背 ArUco 跟踪）；
5. 就位判定通过，手指按策略预张开，随后**力控闭合**：接触物体后按力矩阈值停止，稳稳抓住；
6. 说"放下"，手指张开释放；
7. 全程演示控制环抖动对比数据与资源占用（证明 FPGA 的作用）。

## 3. 功能清单（每个模块做什么）

### F1 语音命令模块（PS）
- 输入：麦克风音频
- 做什么：离线中文命令词识别（Vosk 小模型），解析出目标物品类别和动作（抓/放/张/合）
- 输出：结构化指令（`{action: grasp, target: banana}`）
- 验收：命令词表内识别可靠，端到端 ≤2s

### F2 视觉感知模块（PL/DPU 优先，PS 兜底）
- 输入：俯视 USB 相机视频流
- 做什么：
  a) YOLO 检测目标物体（COCO 预训练模型，零训练）；
  b) 俯视单目几何测尺寸（安装高度已知 → mm/pixel 恒定 → bbox 换算物理尺寸）；
  c) ArUco 跟踪手背标记，计算手-物体相对偏移，生成就位引导；
- 输出：物体类别/位置/朝向/尺寸 + 手就位信号
- 验收：检测可用、尺寸误差 ≤10%、引导到位 ≤30s

### F3 抓取策略模块（PS）
- 输入：F2 的类别/尺寸/朝向
- 做什么：查预标定的抓取参数表 → 每类物品对应：抓取模式（包握/捏/侧捏）、4 指 × 2 舵机的目标角度、闭合速度、力矩上限
- 参数来源：实物标定 + **MuJoCo 数字孪生离线验证**（用官方 AHSimulation 模型验证每 组关节角能否稳定包住该类物体）
- 输出：8 个关节角目标 + 力矩阈值（发给 PL）
- 验收：参数表覆盖全部物品类别，每条有仿真或实测依据

### F4 实时控制模块（PL，RTL —— 作品的 FPGA 核心）
- 输入：F3 的目标角度与力矩阈值（AXI 寄存器）
- 做什么：
  a) **舵机总线控制器**：8 路半双工 TTL UART（1Mbps）并发，1kHz 周期下发位置指令并回读位置/力矩/温度；
  b) **力控抓握状态机**：预张 → 匀速闭合 → 力矩/位置阈值触发停止 → 保持 → 释放；堵转/超温立即降扭矩（安全逻辑）；
- 输出：舵机总线信号
- 验收：控制环 1kHz、P99 抖动微秒级、保护动作可被 ILA 捕获
- **为什么必须是 FPGA**：堵转保护是毫秒级物理事件，Linux 软件环的毫秒级抖动不可控；RTL 确定环不可替代——这是评分 25 分的核心论据

### F5 性能对比与数据采集（贯穿）
- 做什么并产出实测数据：
  - 软件控制环 vs RTL 控制环的周期抖动对比（P99）；
  - YOLO：DPU 吞吐 vs A53-NCNN 吞吐（若 DPU 调通）；
  - 端到端延迟（语音结束→手指到位）；
  - 每类物品 ≥20 次闭环成功率；
  - PL 资源占用表（LUT/DSP/BRAM）。
- 这些数据直接支撑评分中"性能与资源优化 20 分"和"功能正确性 20 分"

### F6 数字孪生（轻量，1~2 天）
- 做什么：用官方 MuJoCo 模型（AHSimulation）离线验证 F3 的抓取参数；仿真与实物同角度并排演示
- 不做：Simulink 从零建模、FPGA→仿真实时同步的完整孪生系统（写入报告展望，作为后续项目构想）

## 4. 明确不做什么

- 不做机械臂/自动到达（人手持手，人提供到达能力）
- 不做 VLA / 本地大模型 / 云端 API 实时链路（端侧小模型为主链路，VLA 论证写入报告）
- 不自建 PYNQ 镜像（用 ALINX Ubuntu 镜像）
- 不自采训练数据集（检测用 COCO 预训练；抓取参数靠标定+仿真验证）
- 不做双目/三维重建（垂直俯视单目几何足够）

## 6. 风险兜底（一句话版）

- DPU 调不通 → A53 NCNN 跑 YOLO（抓取任务 1 FPS 即够），闭环不塌方；
- 力控标定烧舵机 → 预购 2~3 个备用 SCS0009；
- 检测受现场光照影响 → 固定桌面 + 补光灯 + 置信度阈值自适应。
